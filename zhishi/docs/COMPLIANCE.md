# 知势 — 合规白皮书（禁荐股边界）

> 版本：1.0.0 · 适用：未持有中国证监会证券投资咨询许可的运营主体

## 1. 法律定性

向投资者销售或提供具备下列一项或多项功能的软件并直接/间接收费，属于证券投资咨询业务，须经证监会许可：

1. 对具体证券品种提供投资分析意见，或预测价格走势  
2. 提供具体证券品种选择建议  
3. 提供具体证券品种买卖时机建议  
4. 其他证券投资分析、预测或建议  

**知势 MVP 定位**：投资教育工具 + 知识付费，**不构成**上述荐股软件。

## 2. 允许 vs 禁止

| 允许 | 禁止 |
|------|------|
| 通用方法论课程、制度规则释义 | 「建议买入/卖出 XXX」「目标价」「明日必涨」 |
| 历史案例复盘（标注历史、教学） | 持续性个股荐股服务、直播带票 |
| 用户自填检查清单 + 机械「课程框架自检分」 | 将自检分包装成投资建议 |
| 公开行情事实 + 规则释义 | 账号/商标使用未许可「证券」「投资顾问」字样 |
| 模拟盘、错题本、能力测评 | 承诺收益、跟单、代客理财话术 |
| 微信支付知识付费（课包/会员） | 按「荐股软件」「稳赚系统」卖点收费 |

## 3. 产品输出词表（强制）

| 字段 | 允许值 | 禁止值 |
|------|--------|--------|
| `posture` | 偏强学习态 / 中性观察态 / 偏弱学习态 / 数据不足 | 买入、卖出、加仓、减仓、Buy、Sell |
| 页面主分 | `primary_score`（框架自检分） | 多分数互掐、Composite 并列 |
| CTA | 写入复盘本、学习下一项检查 | 一键跟单、立即买入 |

全站固定条：「本产品为投资教育工具，不构成任何投资建议。市场有风险，决策须自负。」

## 4. 营销与类目

- 微信小程序类目：教育 / 在线教育 / 知识付费（以微信当期类目为准）  
- 获客内容：复盘拆解、制度科普；**禁止**带票与收益承诺  
- 自 2026-09-30《金融产品网络营销管理办法》起，不做金融产品营销话术，不做未许可金融字样蹭流量  

## 5. 数据与用户

- 教学演示可用延迟/日线公开数据；商用生产须有授权（见 [DATA_SOURCES.md](./DATA_SOURCES.md)）  
- 用户复盘本为用户私有数据；不对外展示「晒单收益」排行榜  

## 6. 升级路径（持牌后）

仅在与持牌证券投资咨询机构或券商投教/投顾达成书面合作后，方可评估「建议类」能力；无牌 **不开**。详见 [LICENSED_PARTNER.md](./LICENSED_PARTNER.md)。
