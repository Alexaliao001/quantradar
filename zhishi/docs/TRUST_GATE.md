# 知势 — Trust Gate（中文版）

> 借鉴 QuantRadar Trust Gate 哲学，语义改为投教；违反 = 禁止推付费。

## 铁律

| ID | 规则 |
|----|------|
| ZG-1 | 页面上 **最多 1 个** 主分数，字段名 `primary_score`（框架自检分）。禁止同时展示多个综合分。 |
| ZG-2 | `posture` 与标题/CTA 文案 **一致**。不允许「偏弱学习态」旁放「抓紧上车」。 |
| ZG-3 | **禁止** 无出处 testimonials；禁止硬编码假用户数/假胜率。早期用「Beta · 教学案例」。 |
| ZG-4 | 定价文案全站一致（¥68/月 · ¥488/年）。 |
| ZG-5 | Demo 案例走预缓存 artifact，**不扣额度、不打 live 行情**。 |
| ZG-6 | 无数据 / 假代码 **fail-closed**：不给分、不编叙事。 |
| ZG-7 | 输出仅用教学姿态词；禁止买卖指令与目标价。 |
| ZG-8 | 品牌图自托管；禁止外链 CDN 冒充本站。 |
| ZG-9 | 收款前：用户协议 / 隐私 / 不构成投资建议 三页可访问。 |
| ZG-10 | 产品登录不得依赖第三方「荐股」账号体系；会话自有。 |

## 档位

| 档 | 定位 |
|----|------|
| 访客 / 免费 | 规则短课 + 3 个 Demo 案例 |
| 月度研习 | 无限自检 + 复盘本 + 提醒 |
| 年度 | 同上 + 港股通课包 + 错题本 |

对外卖 **可审计的课程框架自检 + 单一学习姿态 + methodology**；不卖荐股幻觉。
