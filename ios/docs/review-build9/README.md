# QuantRadar build 9 — 2026-09-06

This update replaces the quick-tag-only journal with a free, native written-plan and process-review workflow. Plan is the default tab. Saving preserves the original reason, trigger, invalidation and review date; a single later review is appended separately. Existing journal data is retained, same-day entries remain distinct, and new entries no longer silently evict older ones.
